# Pixelize

A cartoonish Unity mobile game where players dismantle pixelized pictures (displayed as colored dots) by sending colored workers one at a time. Workers can only collect/remove dots of their own color. Only edge pixels are removable.

## Game Concept

- **Splash Screen**: Cartoonish worker background with "Pixelize" title in bold font with border all around.
- **Main Menu**:
  - New Level / Continue button (starts at level 1, progresses on success).
  - Settings: Toggle/volume for Sound and Music.
  - Top-left: Coins display + green bill button for IAP (buy coins with real money).
  - Bottom: Progress bar (points from levels; at max, award bonus token).
  - Bonus tokens button with suggestive image.
  - Cartoonish background related to workers and pixels (e.g., pixel factory with cartoon workers assembling/dismantling pixel art).
- **Loading**: On new level, show splash while building game screen.
- **Game Screen**:
  - Upper ~40%: Frame with pixelized image (dots grid). Only edge dots can be hammered out.
  - Below: 5 worker boxes with little forklifts. Each holds one worker.
  - 5 rows of colored workers (balanced, only 4 visible per row). Tap to load into empty box (removes from row, shifts others forward).
  - From box, worker jumps to frame and removes all available matching-color edge pixels.
  - Below workers: 3 bonus token buttons with counts in corner.
- **Bonus Tokens**:
  1. Special two random colored worker.
  2. Extra worker box.
  3. Remove all dots of a user-selected color.
- **Goal**: Completely dismantle the picture by sequencing workers correctly.
- **Monetization**: IAP for coins; coins for boosts or cosmetics (extensible).

## Setup Instructions

1. Install Unity Hub and Unity 2022.3 LTS or newer (2D or 3D Mobile template recommended).
2. Create a new Unity project (2D Core or Mobile).
3. Clone this repo or download the Assets folder.
4. Copy the contents of `Assets/` into your Unity project's `Assets/` folder.
5. Open the project in Unity. It will generate necessary .meta files and Library.
6. Set build target to Android or iOS in File > Build Settings.
7. Configure Player Settings: Company Name, Product Name "Pixelize", Bundle ID (e.g., com.yourname.pixelize), IL2CPP, etc.
8. Import any required packages (e.g., for IAP: Unity Purchasing).
9. Create scenes:
   - Splash.unity
   - MainMenu.unity
   - Game.unity
10. Attach scripts to GameObjects as needed (see script comments).
11. Add placeholder sprites for workers, pixels, forklifts, UI elements (cartoon style).
12. Build and run on device or emulator.

## Implementation Notes

- Pixel removal: Check 4-neighbors; if any is empty/border, it's an edge and removable by matching color worker.
- Worker queues: Use lists/queues; visible 4 per row, shift on dequeue.
- Animations: Use DOTween or Unity Animator for forklift load, worker jump, hammer.
- Persistence: PlayerPrefs or JSON for coins, level progress, token counts, settings.
- IAP: Stub with Unity IAP or RevenueCat; green bill opens shop popup.
- Progress bar: Accumulate points per level; threshold for bonus token reward.
- Levels: ScriptableObjects or JSON defining pixel grids (color maps), available workers, rewards.
